# READ ME

##requisitos

Para conseguir rodar o jogo milky-way primeiro deve-se baixar as dependências correspondentes, de preferência em um ambiente virtual do python(.venv).

- python 3 (instale o python [aqui](https://www.python.org/downloads/))
- pygame-ce (pip install pygame-ce)

##rodando

Entre no diretório do projeto e Execute ```python main.py```.
